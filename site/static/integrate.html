Integrate

Drop the cache into another GoDesk app.

Copy the integration directory or point a script tag at a release. The token stays in the environment.

Python

import os
from cache_me_outside import Client

client = Client(os.environ["CMO_API"], os.environ["CMO_ADMIN_TOKEN"])
print(client.list_databases())

Browser or Node

const cache = CacheMeOutside.attach({
  api: process.env.CMO_API,
  token: process.env.CMO_ADMIN_TOKEN
});
const rows = await cache.listDatabases();

Sidecar

CMO_API=http://127.0.0.1:8088 \
CMO_ADMIN_TOKEN="$CMO_ADMIN_TOKEN" \
python3 integration/sidecar.py

Then GET http://127.0.0.1:8099/health from the app.

This build

The running site reports its integration version. Updating is a separate command, integration/updater.py, and it checks a published checksum before replacing files.

Cache Me Outside agent

It can open the console from here. It cannot read a token out of the repository, because there isn't one.
