What it does

Everything on this page is Cache Me Outside. Names of other products appear only where a card points at a similar feature.

Databases

Each database gets a port, a password that is returned once, and a key prefix. A limit of zero means unlimited.

Key browser

Browse is read-only. It will not return a key that sits outside the database prefix, and it will not run a write.

Live flow

Requests split into a near-cache hit, a cache hit, or a miss that continues to the database.

Warm restart

A clean shutdown can leave a checkpoint for the next process when the usual snapshot did not. It stays off until you turn it on.

Hybrid storage

Large strings can spill to a flash log. That path stays off until you configure it.

TTL segments

Keys that expire in the same time bucket can be removed together. That path stays off until you configure it.
